# NPL wallpaper assets

Drop **your own** JPEG/PNG/WebP files here (mountains, culture, cities, etc.).

## Naming

Files are published as `npl_<name>.webp` in the ROM. Use descriptive names:

- `everest.jpg` → `npl_everest.webp`
- `pashupatinath.png` → `npl_pashupatinath.webp`

## Optional flags (empty marker files)

| File | Effect |
|------|--------|
| `SET_NPL_DEFAULT` | First injected wallpaper becomes the default home wallpaper |
| `order.txt` | One filename per line to control picker order |

## Image tips

- Landscape or square, at least **2400 px** on the long edge (3088 for best quality on S23)
- Use photos you own or that are clearly licensed for redistribution
- Rebuild: Step 4 force rebuild after adding or changing images
